## Read this first

### The 3 rules that prevent most mistakes

**Rule 1: Tasks 2 to 5 must be done INSIDE the lab VM, not in Cloud Shell.**
The checker looks for your files on the VM. If you run the commands in Cloud Shell, they work but the task stays red.

| Prompt looks like | You are in | Use it for |
|-------------------|-----------|------------|
| `student_xx@cloudshell:~ (project-id)$` | Cloud Shell | Only the "Enable the 3 APIs" step |
| `student_xx@lab-vm:~$` (VM name from your lab) | **The lab VM** | **Tasks 2, 3, 4, 5** |

**Rule 2: Use `nano` to create files.** Pasting long multi-line text with `cat <<EOF` often gets garbled in the terminal. `nano` is safer.
- Save: **Ctrl+O**, then **Enter**
- Exit: **Ctrl+X**

**Rule 3: Variables disappear.** Every time you open a new SSH window, run Step 2 again.

## Task 2: Text-to-Speech

🖥️ **INSIDE THE VM**

### 2.1 Create the request file

```bash
# 🔒 COPY AS IS
nano synthesize-text.json
```

Paste this, then **Ctrl+O**, **Enter**, **Ctrl+X**:

```json
{"input":{"text":"Cloud Text-to-Speech API allows developers to include natural-sounding, synthetic human speech as playable audio in their applications. The Text-to-Speech API converts text or Speech Synthesis Markup Language (SSML) input into audio data like MP3 or LINEAR16 (the encoding used in WAV files)."},"voice":{"languageCode":"en-gb","name":"en-GB-Standard-A","ssmlGender":"FEMALE"},"audioConfig":{"audioEncoding":"MP3"}}
```

> This is the lab's JSON written on one line with double quotes, which is the safest form.

Check it:

```bash
# 🔒 COPY AS IS
cat synthesize-text.json
```

### 2.2 Call the API

```bash
# 🔒 COPY AS IS
curl -s -H "Content-Type: application/json; charset=utf-8" -X POST \
  -d @synthesize-text.json \
  "https://texttospeech.googleapis.com/v1/text:synthesize?key=${API_KEY}" > "$TTS_OUT"
head -c 100 "$TTS_OUT"; echo
grep -q audioContent "$TTS_OUT" && echo "✅ Got audio data" || echo "❌ No audio. Read the error above."
```

**Expected:** it starts with `{ "audioContent": "...` and shows `✅`. If you see `"error"`, see Troubleshooting.

### 2.3 Create the decoder script

```bash
# 🔒 COPY AS IS
nano tts_decode.py
```

Paste the script from **your lab page** (Task 2), or this copy of it, then **Ctrl+O**, **Enter**, **Ctrl+X**:

```python
import argparse
from base64 import decodebytes
import json

"""
Usage:
        python3 tts_decode.py --input "synthesize-text.txt" \
        --output "synthesize-text-audio.mp3"

"""

def decode_tts_output(input_file, output_file):
    """ Decode output from Cloud Text-to-Speech.

    input_file: the response from Cloud Text-to-Speech
    output_file: the name of the audio file to create

    """

    with open(input_file) as input:
        response = json.load(input)
        audio_data = response['audioContent']

        with open(output_file, "wb") as new_file:
            new_file.write(decodebytes(audio_data.encode('utf-8')))

if __name__ == '__main__':
    parser = argparse.ArgumentParser(
        description="Decode output from Cloud Text-to-Speech",
        formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument('--input',
                       help='The response from the Text-to-Speech API.',
                       required=True)
    parser.add_argument('--output',
                       help='The name of the audio file to create',
                       required=True)

    args = parser.parse_args()
    decode_tts_output(args.input, args.output)
```

Check the file ended correctly. The last line should be `decode_tts_output(args.input, args.output)`:

```bash
# 🔒 COPY AS IS
tail -3 tts_decode.py
```

### 3.2 Call the API and save the result

```bash
# 🔒 COPY AS IS
curl -s -X POST -H "Content-Type: application/json" --data-binary @"$SPEECH_REQUEST" \
  "https://speech.googleapis.com/v1/speech:recognize?key=${API_KEY}" > "$SPEECH_RESPONSE"
cat "$SPEECH_RESPONSE"
grep -q '"transcript"' "$SPEECH_RESPONSE" && echo "✅ Transcript found in $SPEECH_RESPONSE" || echo "❌ No transcript. Read the response above."
```

**Expected:** a `results` list with a French `transcript` and a `✅` line.

## Troubleshooting

| What you see | Why | Fix |
|--------------|-----|-----|
| Commands work but a task stays red | You ran them in **Cloud Shell**, not the VM | Open the VM's SSH window and redo the task there |
| Task 3 says "Please make sure that your call to the Speech API executed successfully" | Response file has the wrong name, is missing, or holds an error | Compare `$SPEECH_RESPONSE` with the name on your lab page (it may be `speech_response_fr.json`), fix it in Step 2, redo 3.2, and make sure it shows `✅` |
| `❌ API_KEY is not set` | The placeholder was not replaced | Paste your key in the `API_KEY` line in Step 2 and run the block again |
| An empty value or a missing file name | Variables were lost (new SSH window) | Run Step 2 again |
| Weird text like `EOF }` or scrambled lines after pasting | Long paste got garbled | Use `nano` and paste once, then check with `cat` |
| `API key not valid` or empty key | Key missing or wrong | Copy it again from Credentials and redo Step 2 |
| `"error"` mentioning `has not been enabled` | One of the 3 APIs is turned off | Go to **"Enable the 3 APIs"**, enable them (in Cloud Shell or the console, not the VM), wait 30 seconds, retry |
| JSON parse error in Task 2 | Typo or garbled paste in `synthesize-text.json` | Recreate it with `nano` using the one-line version above |
| `synthesize-text-audio.mp3` is 0 bytes or missing | Decoder failed or the Task 2 response has an error | Run `head -c 300 "$TTS_OUT"` and fix the error first |
| Sample rate error in Task 3 | Audio header mismatch | Add `"sampleRateHertz": 44100` inside `config` and retry |
| Task 4 or 5 returns an error about the request | The sentence was typed wrong in Step 2 | Fix the sentence exactly as on your page (including the `%` characters in Task 5) and run Step 2 again |
| Check my progress still red | Checker is slow | Wait 20 seconds and click again, or `cat` the output file to confirm it has a real result |
