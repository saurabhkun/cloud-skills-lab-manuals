## Read this first

### The 6 rules that prevent most mistakes

**Rule 1: Values differ per attempt.** Before you click Start Lab, the page shows blanks such as `Bucket Name`, `Topic Name` and `<filled in at lab start>`. After you start, real values appear. Read them from the live page (Step 0).

**Rule 2: Everything runs in Cloud Shell.** Your prompt should say `cloudshell`.

**Rule 3: Create the files with `nano`, not a long paste.** Pasting a long `cat <<EOF` block into Cloud Shell often garbles the code (you get junk like `lsd"node": ">=4.3.2"{}`). `nano` is safe. Always run the check in 3.3 before deploying.

**Rule 4: Be inside the `thumbnails` folder when you deploy.** If your prompt shows only `~`, you are in the home folder. The deploy then fails with `Provided source directory does not have file [package.json]`. The deploy block in 3.4 moves you there for you.

**Rule 5: Fix the Eventarc permissions first and wait.** A new project often fails the first deploy with `Permission denied while using the Eventarc Service Agent`. Task 3.1 prevents this, and the deploy in 3.4 retries by itself.

**Rule 6: Upload the test image AFTER the function is deployed.** The trigger only fires for files uploaded after the function exists. An image uploaded earlier never gets a thumbnail.

## Task 3: Create the Cloud Run function

☁️ **CLOUD SHELL**

### 3.1 Fix permissions first

Set the numbers and create the service agents:

```bash
# 🔒 COPY AS IS
export PROJECT_NUMBER=$(gcloud projects describe $PROJECT_ID --format='value(projectNumber)')
export COMPUTE_SA=${PROJECT_NUMBER}-compute@developer.gserviceaccount.com
gcloud beta services identity create --service=eventarc.googleapis.com --project=$PROJECT_ID
gcloud beta services identity create --service=pubsub.googleapis.com --project=$PROJECT_ID
export GCS_SA=$(gcloud storage service-agent --project=$PROJECT_ID)
echo "Project number: $PROJECT_NUMBER"
echo "Compute account: $COMPUTE_SA"
echo "Storage agent  : $GCS_SA"
```

All three lines must show values. Now grant the five roles. This block prints a short `✅` or `❌` for each one:

```bash
# 🔒 COPY AS IS
grant() {
  gcloud projects add-iam-policy-binding $PROJECT_ID --member="serviceAccount:$1" --role="$2" --condition=None --quiet >/dev/null 2>&1 \
    && echo "✅ $2" || echo "❌ FAILED: $2 for $1 (wait 30 seconds and run this block again)"
}
grant "$GCS_SA" roles/pubsub.publisher
grant "$COMPUTE_SA" roles/eventarc.eventReceiver
grant "$COMPUTE_SA" roles/pubsub.publisher
grant "service-${PROJECT_NUMBER}@gcp-sa-eventarc.iam.gserviceaccount.com" roles/eventarc.serviceAgent
grant "service-${PROJECT_NUMBER}@gcp-sa-pubsub.iam.gserviceaccount.com" roles/iam.serviceAccountTokenCreator
```

**Expected:** five `✅` lines. If a line says `❌`, wait 30 seconds and run the block again (a service agent can take a moment to appear).

### 3.2 Create the files with nano

```bash
# 🔒 COPY AS IS
mkdir -p ~/thumbnails && cd ~/thumbnails
nano index.js
```

> [!IMPORTANT]
> 🔒 Paste the code below **exactly as it is**. Leave `FUNCTION_NAME_HERE` and `TOPIC_NAME_HERE` alone. The next command fills them in with your names, so you do not edit them.

Paste this, then **Ctrl+O**, **Enter**, **Ctrl+X**:

```javascript
const functions = require('@google-cloud/functions-framework');
const { Storage } = require('@google-cloud/storage');
const { PubSub } = require('@google-cloud/pubsub');
const sharp = require('sharp');

functions.cloudEvent('FUNCTION_NAME_HERE', async cloudEvent => {
  const event = cloudEvent.data;

  console.log(`Event: ${JSON.stringify(event)}`);
  console.log(`Hello ${event.bucket}`);

  const fileName = event.name;
  const bucketName = event.bucket;
  const size = "64x64";
  const bucket = new Storage().bucket(bucketName);
  const topicName = "TOPIC_NAME_HERE";
  const pubsub = new PubSub();

  if (fileName.search("64x64_thumbnail") === -1) {
    // doesn't have a thumbnail, get the filename extension
    const filename_split = fileName.split('.');
    const filename_ext = filename_split[filename_split.length - 1].toLowerCase();
    const filename_without_ext = fileName.substring(0, fileName.length - filename_ext.length - 1); // fix sub string to remove the dot

    if (filename_ext === 'png' || filename_ext === 'jpg' || filename_ext === 'jpeg') {
      // only support png and jpg at this point
      console.log(`Processing Original: gs://${bucketName}/${fileName}`);
      const gcsObject = bucket.file(fileName);
      const newFilename = `${filename_without_ext}_64x64_thumbnail.${filename_ext}`;
      const gcsNewObject = bucket.file(newFilename);

      try {
        const [buffer] = await gcsObject.download();
        const resizedBuffer = await sharp(buffer)
          .resize(64, 64, {
            fit: 'inside',
            withoutEnlargement: true,
          })
          .toFormat(filename_ext)
          .toBuffer();

        await gcsNewObject.save(resizedBuffer, {
          metadata: {
            contentType: `image/${filename_ext}`,
          },
        });

        console.log(`Success: ${fileName} → ${newFilename}`);

        await pubsub
          .topic(topicName)
          .publishMessage({ data: Buffer.from(newFilename) });

        console.log(`Message published to ${topicName}`);
      } catch (err) {
        console.error(`Error: ${err}`);
      }
    } else {
      console.log(`gs://${bucketName}/${fileName} is not an image I can handle`);
    }
  } else {
    console.log(`gs://${bucketName}/${fileName} already has a thumbnail`);
  }
});
```

### 3.4 Deploy

```bash
# 🔒 COPY AS IS ⏳ (runs from inside ~/thumbnails and retries by itself if permissions are still spreading)
cd ~/thumbnails
for attempt in 1 2 3; do
  gcloud functions deploy $FUNCTION \
    --gen2 \
    --runtime=nodejs22 \
    --region=$REGION \
    --source=. \
    --entry-point=$FUNCTION \
    --trigger-bucket=$BUCKET && break
  echo "⏳ Deploy attempt $attempt did not finish. Waiting 60 seconds, then trying again..."
  sleep 60
done
```

Answer `y` if it asks to enable an API. It takes a few minutes and ends with `state: ACTIVE`.

Verify:

```bash
# 🔒 COPY AS IS
gcloud functions describe $FUNCTION --region=$REGION --gen2 --format="value(state,eventTrigger.eventType)"
```

**Expected:** `ACTIVE` and `google.cloud.storage.object.v1.finalized`. A `404 was not found` here means the deploy has not succeeded yet.

## Troubleshooting

| What you see | Why | Fix |
|--------------|-----|-----|
| `❌ ... is not set correctly` in step 1.2 | A `YOUR_...` placeholder was not replaced | Fix that line in step 1.1 and run 1.1 and 1.2 again |
| `❌ REGION ... does not look like a region` | The region was typed wrong | Copy it from the lab page, for example `us-central1` |
| Score stuck at 25 | Function not deployed, or no thumbnail yet | `gcloud functions list --regions=$REGION`, then finish 3.4 and Task 4 |
| `❌ FAILED:` on a role in 3.1 | The service agent was not created yet | Wait 30 seconds and run the grant block again |
| `cd: ~/thumbnails: No such file or directory` | Folder never created | Run `mkdir -p ~/thumbnails && cd ~/thumbnails`, then redo 3.2 |
| `Provided source directory does not have file [package.json]` | Deploying from the wrong folder, or file missing | `cd ~/thumbnails`, run `ls`, then deploy again |
| Junk characters inside `index.js` or `package.json` | Long paste got garbled | Delete with `rm index.js package.json`, recreate with `nano`, run the 3.3 checks |
| `❌ index.js still has _HERE` | The `sed` fill-in did not run or variables were empty | Redo Step 1, then run the `sed` block in 3.2 again |
| `Permission denied while using the Eventarc Service Agent` | Permissions not propagated yet | The deploy retries by itself. If all 3 attempts fail, wait 2 to 3 minutes and run 3.4 again |
| Describe says `404 was not found` | Function not deployed | Fix the deploy error first, then describe again |
| `gs:///` or empty values | Variables lost | Redo Step 1 |
| Checker says to upload an image | Image uploaded before the function existed | Upload a new copy (`travel2.jpg`) after the function is ACTIVE |
| `❌ No thumbnail yet` | Trigger slow or function error | `gcloud functions logs read $FUNCTION --region=$REGION --gen2 --limit=20`, wait a couple of minutes, upload another copy |
| Check my progress still red | Checker is slow | Wait 20 seconds and click again |
