The lab says to enable the APIs needed to call Gemini. In Cloud Shell, this is one command:

```bash

```

**Expected:** `Operation ... finished successfully.` Then wait for it to spread:

```bash
# 🔒 COPY AS IS ⏳ (waits 30 seconds by itself)
for i in 1 2 3; do echo "⏳ Letting the API switch on... $((i*10))s of 30s"; sleep 10; done
echo "✅ Done waiting"
```

### 1.4 Ask the question

```bash
# 🔒 COPY AS IS
curl -s -X POST \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  "https://${API_ENDPOINT}/v1/projects/${PROJECT_ID}/locations/${LOCATION}/publishers/google/models/${MODEL_ID}:streamGenerateContent" \
  -d '{"contents": {"role": "user", "parts": {"text": "Why is the sky blue?"}}}' > gemini-response.json
head -c 700 gemini-response.json; echo
grep -q '"text"' gemini-response.json && echo "✅ Gemini answered" || echo "❌ No answer. Read the response above."
```

**Expected:** a `✅` line and text about light scattering in the output. Click **Check my progress** for Task 1.

> [!NOTE]
> If the answer shows an error about the API not being enabled, wait a minute and run 1.4 again. If you see a `429`, wait a minute and retry. If the check stays red, change `:streamGenerateContent` to `:generateContent` in the command and run it again.

## Troubleshooting

| What you see | Why | Fix |
|--------------|-----|-----|
| `❌ ... is not set correctly` in Step 1.2 | A `YOUR_...` placeholder was not replaced | Fix that line in 1.1 and run 1.1 and 1.2 again |
| `❌ No answer` in 1.4 | The API is not on yet, or a value is wrong | Wait a minute and run 1.4 again. Read the error in the output |
| `429` error anywhere | Too many requests in a short time | Wait one minute and run the same cell or command again |
| Task 1 check stays red | The checker may expect a different call form | Change `:streamGenerateContent` to `:generateContent`, run 1.4 again, wait 20 seconds, check again |
| Can't find Workbench in the menu | Menu names differ | Search "Workbench" in the console search box |
| `NameError: name 'client' is not defined` | The kernel restarted or the client cell was skipped | Run the client cell, then the imports cell, then retry |
| `NameError` for `FunctionDeclaration`, `Tool` or `Part` | The imports cell was skipped | Run the imports cell, then retry |
| `NameError: print_multimodal_prompt` | The helper cell was skipped | Run the helper cell (4.2), then rerun 4.3 |
| Model not found | The model name is misspelled | Copy `MODEL_ID` from your lab page exactly, with the quotes |
| Function call output is empty | Cells 3.2 and 3.3 were not run first | Run 3.2, 3.3, then 3.4 again |
| Task 3 or 4 check stays red | The notebook was not saved, or the cell did not run | Make sure the cell printed output, press **Ctrl+S**, wait 20 seconds, click again |
| Video description does not appear | The cell is still running, or a 429 happened | Wait for the cell to finish, or wait a minute and rerun it |
