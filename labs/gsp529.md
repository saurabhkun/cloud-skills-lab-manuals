## Read this first

### The 4 rules that prevent most mistakes

1. **Connect Google Drive and close the pop-up (Task 1):** Once Drive is connected, AI Studio **autosaves your app to Drive** after every generation. The lab checker inspects this saved Drive copy. If Drive is not connected, your app will not save and every task check will remain red.
2. **Wait for generation to complete before checking:** Never click "Check my progress" while AI Studio is still streaming responses or rendering components. Allow the live preview to fully settle so the autosave syncs.
3. **Keep exact lab names:** The automated grading engine looks for specific element names:
   - **Buttons:** `Generate Portrait`, `Regenerate Portrait`, `Generate Backstory`, `Save to Deck`
   - **List:** `My Deck`
   - **Stats:** `Health`, `Mana`, `Strength`
   - **App Name:** `Fantasy Character Generator`
4. **Use your student account in Incognito:** Personal Google accounts will not sync with the lab's assessment environment.

## Task 1: Generate the core app

🎨 **AI STUDIO**

1. Open the app builder interface (the **Build** or "vibe coding" view with a prompt box and preview canvas).
2. Copy and paste this prompt:

```text
Build a simple Fantasy Character Creator web app. It has one button, "Generate Character". When clicked, it generates and displays a random fantasy character with a unique Name and a Class (such as Mage, Rogue, Warrior, Paladin, Ranger). Use Gemini to generate the name and class.
```

3. Wait for the preview to render. Click **Generate Character** once to verify functionality.

### Connect Google Drive (Crucial)

The lab requires Google Drive integration so it can inspect your saved prototype and enable continuous autosave.

1. Open the **Add files** menu (or the **`+`** icon near the prompt input).
2. Select **Drive**.
3. In the authentication modal, choose the **student account** and grant permissions.
4. 🛑 **Close the Drive pop-up** once authorized. Do not leave the modal open.

### Confirm Autosave

1. Allow several seconds after the preview updates for autosave to complete.
2. Confirm the app title at the top is `Fantasy Character Generator` (rename it if needed).
3. Click **Check my progress** for Task 1.

## Troubleshooting

| Issue | Cause | Resolution |
|:---|:---|:---|
| "Check my progress" stays red | Autosave was pending while generating | Wait 20–30 seconds after the preview renders completely, then recheck. |
| Task 1 fails repeatedly | Google Drive was not linked properly | Click `+ Add files` > `Drive`, sign in with student account, and close the pop-up modal. |
| Nothing saves | Drive disconnected | Re-authenticate Drive, trigger a minor prompt edit, and verify autosave triggers. |
| App title discrepancy | Default title was kept | Rename the prototype in the top title field to exactly `Fantasy Character Generator`. |
| Button or feature missing | Model dropped an element during rewrite | Send a follow-up: *"The 'Regenerate Portrait' button is missing. Please add it back while preserving all other features."* |
| Portrait fails to render | Image API transient hiccup | Prompt: *"The portrait image failed to display. Please regenerate and handle the display container."* |
| Deck entries disappear | State management issue in preview | Prompt: *"Ensure 'Save to Deck' persists characters in the visible 'My Deck' list across generations."* |

## Golden Tips for AI Studio Labs

- **Keep one conversation thread:** Never start a new chat between tasks. Context memory ensures subsequent prompts extend your existing prototype rather than resetting it.
- **Do not overwrite named elements:** If an iteration removes a previous button, request that the model restore it before checking progress.
- **Autosave requires closed modals:** Leaving the Google Drive authorization dialog open in the background can prevent background autosave syncs.
- **Never share lab credentials or API tokens in public repositories.**
